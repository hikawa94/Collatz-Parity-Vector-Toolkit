## Overview

The Collatz Parity Vector Toolkit is a collection of software tools for studying
the Collatz Conjecture through Parity Vector analysis and Parity Vector Geometry.

This toolkit accompanies the research presented in the paper

"Parity Vector Analysis in the Study of the Collatz Conjecture"
"Finite-Dimensional Combinatorial and Arithmetic Structures of Parity Vectors for the Accelerated Collatz Map"

The toolkit provides computational verification, visualization,
and numerical experiments based on dynamic programming algorithms.
